Funções de hash e SHA-256

No fim desta lição, será possível explicar o que é uma função de hash, porque o SHA-256 é a base da ligação entre blocos e experimentá-lo.

10 min de leitura2 perguntas · 1 calculadora

Uma impressão digital para dados

Uma função de hash pega em qualquer dado (uma palavra, um livro, um bloco de transações) e devolve um número de tamanho fixo, a que se chama hash. O Bitcoin usa a função SHA-256, que devolve sempre 256 bits, normalmente escritos como 64 caracteres em hexadecimal.

Experimentar

Calculadora de SHA-256

Escrever qualquer texto. Depois mudar uma única letra e ver o que acontece.


    

    
O que se repara

    
    
      
  • O resultado tem sempre o mesmo tamanho, seja o texto de uma letra ou de um livro.
    • 
      
  • O mesmo texto dá sempre o mesmo hash. É determinista.
    • 
      
  • Mudar uma letra muda tudo. Não há «hashes parecidos» para textos parecidos.
    • 
      
  • Não se volta atrás. A partir do hash não se consegue descobrir o texto. A única forma é tentar textos até acertar.
    • 
    

    
Um exemplo conhecido: o SHA-256 de abc é ba7816bf…f20015ad. Pode escrever-se acima para confirmar.

    
Para que serve no Bitcoin

    

      
1 · LIGAR BLOCOS
Cada bloco guarda o hash do anterior
Se alguém mudar um bloco antigo, o hash muda e a ligação quebra-se.

      
2 · RESUMIR TRANSAÇÕES
Raiz de Merkle
Os hashes das transações combinam-se numa árvore. A raiz resume milhares de transações num só valor.

      
3 · PROVAR TRABALHO
Mineração
Os mineradores procuram um bloco cujo hash comece por muitos zeros (lição 1.3).

      
4 · ENDEREÇOS
Das chaves aos endereços
O endereço de uma carteira é derivado da chave pública com funções de hash (lição 5.2).

    

    
O que o SHA-256 não faz

    
O SHA-256 não assina transações: serve para a mineração e para encadear blocos. A assinatura usa outra matemática (curvas elípticas, lição 5.2). Esta distinção importa para a lição sobre o risco quântico: quebrar o SHA-256 não permitiria gastar as moedas de ninguém, ao passo que forjar assinaturas permitiria.

    
O cabeçalho de um bloco

    
O que entra no hash de um bloco é o seu cabeçalho, com 80 bytes e seis campos:

    

      

        
CampoO que é

        
          
VersãoQuais as regras que o bloco segue

          
Hash do bloco anteriorLiga este bloco ao anterior

          
Raiz de MerkleResumo de todas as transações do bloco

          
Data e horaQuando o bloco foi produzido, aproximadamente

          
Alvo de dificuldadeQuantos zeros o hash precisa de ter

          
NonceO número que o minerador vai alterando até acertar

        
      

    

    
Na prática, o Bitcoin aplica o SHA-256 duas vezes seguidas (SHA-256d). Para perceber a ideia, uma vez chega.

    

      Ideia-chave
      Um hash é uma impressão digital: fácil de calcular, impossível de inverter, e qualquer alteração muda-o por completo. É isto que torna a cadeia de blocos infalsificável.
    

    
Verificação


    

      O que acontece ao hash se se mudar uma letra do texto?
      
      
      
      

      

      
É a propriedade a que se chama efeito de avalanche: mudar um bit na entrada muda a saída de forma imprevisível.

    


    

      O SHA-256 assina as transações?
      
      
      
      

      

      
A assinatura usa curvas elípticas. Por isso, quebrar o SHA-256 não permitiria gastar as moedas de ninguém.
